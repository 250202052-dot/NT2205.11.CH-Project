# Public datasets local

Dataset tải về nằm ở đây, tách khỏi code trong `data/public_loaders/`. File NF-UQ-NIDS-v2.csv.zip đã được chuyển từ `data/pub_dataset/` và giữ nguyên; chưa giải nén hay xử lý trong bước sắp xếp thư mục.

Không commit dataset/archive vào Git. Khi triển khai loader, ghi nguồn, license, phiên bản và checksum, rồi tạo training artifact sau privacy validation.
